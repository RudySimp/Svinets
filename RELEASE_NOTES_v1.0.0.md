# Svinets v1.0.0

The first stable release of Svinets for Foundry VTT v14.

## Loot generator

- 90 contexts grouped into 16 categories.
- Context-aware, deterministic generation with exact budget conservation.
- Support for large budgets and bounded coin ranges.
- High-value valuables, trade goods, gemstones, and art objects.
- Generic magic-item generation with explicit mundane/magic focus separation.
- Stack-aware quantity policy for consumables and value carriers.

## Interface

- Context category and place selection.
- Budget and magic controls.
- GM preview with lock, replace, regenerate-unlocked, publish, and close actions.
- Player chat output contains only the approved loot result.

## Compatibility

Foundry VTT v14.
