# Svinets v1.0.0 — Foundry VTT v12

Отдельная версия Svinets для Foundry VTT v12.

## Основа

Функционально соответствует Svinets v1.0.0 для Foundry VTT v14.

## Совместимость

- Foundry VTT v12 only.
- Minimum: 12.
- Verified: 12.
- Maximum: 12.

## Возможности

- 90 контекстов и 16 групп.
- Контекстная генерация и поддержка больших бюджетов.
- Generic magic и stack policy.
- GM Preview, Lock, Replace и Regenerate unlocked.
- Чистая карточка Player Chat.
- Точное сохранение бюджета.

## Port

Интерфейс и интеграция с Foundry адаптированы к публичному API Foundry VTT v12: v12 chat render hook, DialogV2/ApplicationV2, Item.createDocuments, ChatMessage и game.settings.
